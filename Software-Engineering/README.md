# Software Engineering — CS 372 Final Project

This folder contains the submitted source for the Software Engineering course final project.

## Technology
Java, JSP, Servlets, MySQL, JDBC/MySQL Connector, Apache Tomcat, Eclipse, HTML, CSS, and JavaScript.

## Contents
- `src/main/java/` — application models, servlets, data-access classes, and database helpers
- `src/main/webapp/` — JSP pages, web configuration, stylesheets, and JavaScript
- `sql/` — database creation, authentication/content tables, and seed scripts
- `docs/` — project workflow, previews, and diagrams

## Local setup
1. Import the project into Eclipse as an existing web project.
2. Configure a compatible JDK and Apache Tomcat server.
3. Create the MySQL database and tables using the scripts in `sql/`.
4. Configure database access for your local environment; do not commit passwords.
5. Deploy to Tomcat and test locally.
