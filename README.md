# Sydney Thomas — Academic Project Portfolio

This repository contains two university course projects, each organized in its own folder.

## Projects

### 1. Software Engineering — CS 372 Final Project
[Open Software Engineering project](./Software-Engineering/)

Java/JSP and Servlet application using MySQL, JDBC/MySQL Connector, Apache Tomcat, Eclipse, HTML, CSS, and JavaScript. Includes application source, SQL scripts, project documentation, diagrams, and visual previews.

### 2. Programming for the Web — Final Project
[Open Programming for the Web project](./Programming-for-the-Web/)

PHP web application using HTML, CSS, JavaScript, PDO, and MySQL. Includes student and employee workflows, shared PHP libraries, browser scripts, stylesheets, media assets, and the database schema.

## Important
These are academic projects and require their respective local environments to run. The Java/JSP project requires a servlet container and MySQL; the PHP project requires PHP with PDO MySQL support and MySQL/MariaDB.

Never commit passwords, API keys, generated session files, or real student/employee records. Preserve team attribution and publish only materials approved for public sharing.
